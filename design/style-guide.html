01
Design Language
Six principles that define every interaction, layout, and visual decision in the app.
01
Principle · 01
Personality
Minimal · Confident
Not a productivity tool, not a scanner. A quiet, tasteful kitchen companion. High contrast, no noise.
02
Principle · 02
Accent
#FF3B30 — Vivid Red
Single accent color. Reserved for active states, AI features, and primary CTAs only. Never decorative.
03
Principle · 03
Typography
Poppins 400–900
One font family. Geometric, rounded. Negative tracking at display sizes. 15px minimum for all inputs.
04
Principle · 04
Category
8px Colored Dot
Category identity lives in an 8px dot in list rows — not emoji boxes. Color only; no labels in tight rows.
05
Principle · 05
Mode
Dark-first
Base on #0D0D0D canvas. Surfaces on #1A1A1A. Lime pops hard against dark. Light mode fully supported.
06
Principle · 06
Touch
44px · Swipe · dvh
44px minimum touch targets. Swipe-to-delete on every list row. 100dvh + env() safe areas throughout.

07
Mobile-First Rules
Non-negotiable constraints for the 390px iPhone viewport. Break these and the app breaks on device.
44
44px
Minimum Touch Target
Every interactive element must have a 44×44px touch area. Use padding expansion for visually smaller elements like check buttons.
15
15px
Min Input Font Size
All inputs must use ≥ 15px to prevent iOS Safari auto-zoom on focus. Never go below this threshold anywhere.
390
390px
Primary Viewport
Design for iPhone 15 (390px) first. Test at 375px (SE minimum). Max content width: 430px centered.
dvh
dvh
Use 100dvh not 100vh
Dynamic viewport height accounts for browser chrome on mobile. Always use 100dvh for full-height containers.
env
env()
Safe Area Insets
Header: padding-top with safe-area-inset-top. Bottom nav + sheets: padding-bottom with safe-area-inset-bottom.
✦
touch
Touch Events First
Swipe gestures: onTouchStart/Move/End. Every hover state must have an active/touch equivalent. No hover-only states.
